Interpolation quality and performance: FSR3 and recovered Hydra

Each backend processes the same 24 real frames. Metrics score frames 18–23 against the scene rendered directly at n−0.5. Preview images show the last pair; click any image for full resolution. Lower errors are better.

FSR3 receives game motion vectors; fsr3-optical-only receives zero vectors. Hydra receives depth and camera transforms, and estimates object motion from color. Neural refinement is off. Crossfade is a non-motion-compensated baseline.

GPU execution time uses WebGPU timestamp-query: (prepare end − prepare start) + (dispatch end − dispatch start). Each phase spans its first pass beginning to its last pass end, including intervening passes, buffer clears, and GPU transitions. CPU encoding/submission, the gap between submissions, queue completion notification, uniform uploads before the first pass, scene rendering, and query resolve/readback are excluded. GPU clock granularity and timestamp instrumentation can affect measurements. Raw per-phase durations are saved in results.json. Unsupported adapters show GPU timing as unavailable.

End-to-end latency measures wall-clock prepare() + dispatch() through GPU completion, including CPU submission and completion notification overhead. Scene rendering, setup, readback, and image/metric processing are excluded. Each independent replay warms up on frames 1–17 and measures frames 18–23; backend order rotates to reduce ordering bias. Speed is FSR3 median / variant median within each timing method: 2× means twice as fast, 0.5× means twice as slow. These timings are not game FPS. p95 uses the nearest-rank percentile. Crossfade runs on the CPU for quality only and is not benchmarked.

Metrics use linear floating-point RGB, without alpha. Changed-region metrics include pixels where the real frames or the ground truth differ by more than 1/255. PNG previews are sRGB. Error previews amplify absolute linear error by 8 before sRGB conversion. These synthetic scenes do not establish native-SDK parity or general game quality.
